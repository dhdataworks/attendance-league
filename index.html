Connect the dashboard to your published Google Sheet

Paste the published CSV link from your Google Sheet (File → Share → Publish to web → CSV).

How to set up the sheet

Your sheet needs these columns (row 1 = headings):

Group · House · Colour · Week 1 · Week 2 · … (add as many week columns as you need)

One row per group. Leave House blank if you're not using houses. Colour is optional (hex like #e63946). Type attendance percentages into the week columns as they happen.

Then: File → Share → Publish to web → choose the sheet → Comma-separated values (.csv) → Publish → copy the link.
